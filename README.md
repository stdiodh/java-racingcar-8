# java-racingcar-precourse

> 2주차 미션 - 자동차 경주

## 과제 제출 전 체크 리스트

- [ ] 터미널에서 `java --version` 실행하여 Java 버전이 21인지 확인
- [ ] 아래 명령어를 실행하여 실행하여 모든 테스트가 통과하는지 확인
    - Mac/Linux 사용자 : `./gradlew clean test`
    - Windows 사용자 : `gradlew.bat clean test` or `.\gradlew.bat clean test`
- [ ] `BUILD SUCCESSFUL in 0s` 메시지를 확인

---

## 기능 목록

### 1. 입력 기능
- [x] "경주할 자동차 이름을 입력하세요." 안내 문구 출력
- [x] 쉼표(,)로 구분된 자동차 이름 입력받기
- [x] "시도할 횟수는 몇 회인가요?" 안내 문구 출력
- [x] 시도할 횟수 입력받기

### 2. 출력 기능
- [x] "실행 결과" 안내 문구 출력
- [x] 매 경주(라운드)마다 실행 결과 출력
  - 형식 `이름 : -`
- [x] 라운드 진행 후 개행 처리
- [x] 최종 우승자 출력 
  - 형식 : `최종 우승자 : 이름1, 이름2`

### 3. 유효성 검사
- 자동차 이름 검증
  - [x] 이름이 5자를 넘으면 예외 발생
  - [x] 이름이 비어있으면 예외 발생
  - [x] 이름이 중복되면 예외 발생
  - [x] 자동차가 2대 미만이면 예외 발생
- 시도 횟수 검증
  - [x] 입력값이 숫자가 아니면 예외 발생
  - [x] 입력값이 1보다 작으면(0 또는 음수) 예외 발생
  - [x] 검증 완료 시 횟수를 숫자로 반환

### 4. 핵심 기능 (도메인)
- 자동차 (`Car`)
  - [x] 이름(`Name`)과 현재 위치(`Position`)를 가짐
  - [x] 0에서 9 사이의 무작위 값을 전달받음
  - [x] 무작위 값이 4 이상이면 위치를 1 증가시킴

- 자동차 이동 관리 (`Cars` - 일급 컬렉션)
  - [x] 여러 대의 자동차 목록(`List<Car>`)을 관리
  - [x] 생성 시에 2 미만 여부 및 이름 중복 여부 검증
  - [x] 1회의 이동을 실행
    - [x] 모든 차를 움직이게 함
  - [x] 모든 이동이 끝난 후
    - [x] 가장 위치가 높은 자동차(들)을 찾음
    - [x] 우승자(들)의 이름 목록을 반환

### 5. 게임 실행 (제어)
- [x] 게임의 전체 흐름을 제어
- [x] 입력받은 자동차 이름과 시도 횟수를 검증
  - [x] `InputService` : 원시 `String`을 파싱 및 `Domain` 객체로 변환 
- [x] 검증된 이름 목록으로 자동차 경주를 준비
  - [x] `RacingGame` : `InputService`을 통해 `Domain` 객체 생성 및 소유
- [x] "실행 결과" 문구 출력 요청
- [x] 정해진 횟수만큼 이동 반복
  - [x] 이동을 1회 실행
  - [x] 매번 실행 결과를 출력하도록 요청
- [x] 모든 전진이 끝나면 우승자 목록을 요청
- [x] 최종 우승자를 출력하도록 요청

### 6. 테스트
- [x] 자동차 전진/정지 기능 테스트
- [x] 우승자 판별 기능 테스트 (단독/공동 우승)
- [x] 자동차 이름 예외 처리 테스트 (`NameTest`, `CarsTest`, `InputServiceTest`)
- [x] 시도 횟수 예외 처리 테스트 (`TryCountTest`, `InputServiceTest`)
