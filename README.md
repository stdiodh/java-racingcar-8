# java-racingcar-precourse

> 2주차 미션 - 자동차 경주

## 과제 제출 전 체크 리스트

- [ ] 터미널에서 `java --version` 실행하여 Java 버전이 21인지 확인
- [ ] 아래 명령어를 실행하여 실행하여 모든 테스트가 통과하는지 확인
    - Mac/Linux 사용자 : `./gradlew clean test`
    - Windows 사용자 : `gradlew.bat clean test` or `.\gradlew.bat clean test`
- [ ] `BUILD SUCCESSFUL in 0s` 메시지를 확인

---

## 기능 목록

### 1. 입력 기능
- [ ] "경주할 자동차 이름을 입력하세요." 안내 문구 출력
- [ ] 쉼표(,)로 구분된 자동차 이름 입력받기
- [ ] "시도할 횟수는 몇 회인가요?" 안내 문구 출력
- [ ] 시도할 횟수 입력받기

### 2. 출력 기능
- [ ] "실행 결과" 안내 문구 출력
- [ ] 매 경주(라운드)마다 실행 결과 출력
  - 형식 `이름 : -`
- [ ] 라운드 진행 후 개행 처리
- [ ] 최종 우승자 출력 
  - 형식 : `최종 우승자 : 이름1, 이름2`

### 3. 유효성 검사
- 자동차 이름 검증
  - [ ] 이름이 5자를 넘으면 예외 발생
  - [ ] 이름이 비어있으면 예외 발생
- 시도 횟수 검증
  - [ ] 입력값이 숫자가 아니면 예외 발생
  - [ ] 입력값이 1보다 작으면(0 또는 음수) 예외 발생
  - [ ] 검증 완료 시 횟수를 숫자로 반환

### 4. 핵심 기능 (도메인)
- 자동차
  - [ ] 이름과 현재 위치를 가짐
  - [ ] 0에서 9 사이의 무작위 값을 전달받음
  - [ ] 무작위 값이 4 이상이면 위치를 1 증가시킴

- 자동차 이동 관리
  - [ ] 여러 대의 자동차 목록을 관리
  - [ ] 1회의 이동을 실행
    - [ ] 모든 차를 움직이게 함
  - [ ] 모든 이동이 끝난 후
    - [ ] 가장 위치가 높은 자동차(들)을 찾음
    - [ ] 우승자(들)의 이름 목록을 반환

### 5. 게임 실행 (제어)
- [ ] 게임의 전체 흐름을 제어
- [ ] 입력받은 자동차 이름과 시도 횟수를 검증
- [ ] 검증된 이름 목록으로 자동차 경주를 준비
- [ ] "실행 결과" 문구 출력 요청
- [ ] 정해진 횟수만큼 이동 반복
  - [ ] 이동을 1회 실행
  - [ ] 매번 실행 결과를 출력하도록 요청
- [ ] 모든 전진이 끝나면 우승자 목록을 요청
- [ ] 최종 우승자를 출력하도록 요청

### 6. 테스트
- [ ] 자동차 전진/정지 기능 테스트
- [ ] 우승자 판별 기능 테스트 (단독/공동 우승)
- [ ] 자동차 이름 예외 처리 테스트
